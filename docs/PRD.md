# 学费计价器（暂定名 Tuition Ticker）— 产品需求文档 PRD

> 版本：v0.2 ｜ 日期：2026-11-11 ｜ 状态：待评审
> 一句话定位：**把学费换算成「每一秒」，让你在课堂上实时看到自己正在花多少钱、浪费了多少钱。**
> 开源、本地优先、无需账号；导入课表日历后全自动运行。
> 形态：**一个本地文件夹**。双击 `start.cmd` → 在本机启动一个小服务 → 自动用浏览器打开界面。浏览器只负责显示，所有数据以文件形式保存在文件夹内的 `data/` 目录。运行需要 Node.js。

**v0.2 变更**：新增首次启动「按学期 / 按学年」计费周期选择、学期分割日（默认圣诞节，可调）、7 种货币切换；形态改为「本地服务 + 浏览器」；时间以电脑系统时间为准；汇率内置；界面设计阶段使用 Claude Design。

---

## 1. 背景与目标

### 1.1 背景
- 港硕 / 海外授课型硕士学费高（一年 HK$20–40 万很常见），但「学费」是一个一次性交掉、之后就没有体感的数字。
- 小红书上有人做了「上课鼓励器」：把学费按秒换算，上课时实时跳动，还有「摸鱼计时」功能，算出你走神期间浪费了多少钱（≈ 一瓶水 / 一盒三餸饭）。获赞 1.2 万+，说明这个点子在留学生里很有共鸣。
- 原版的问题：需要手动开始计时，没有接入课表，不知道「这是第几节课」，历史消耗靠手填，也不是开源的。

### 1.2 产品目标
1. **零操作自动运行**：导入一次课表日历，之后每到上课时间自动进入「上课中」状态并开始计价，下课自动结束。
2. **算得对**：学期学费、总课时、每秒成本、本节已消耗、历史累计、剩余学费，全部由课表 + 系统时钟推导，可解释、可复现。
3. **好玩、有梗、愿意分享**：摸鱼计时 + 「等价物」换算 + 毒舌文案 + 分享卡片。
4. **开源可复用**：任何学校、任何币种、任何日历来源的学生都能用；隐私数据不出本机。

### 1.3 非目标（本期不做）
- 不做账号体系、云同步、社交排行榜。
- 不登录学校系统（SIS / Moodle）去抓课表 —— 涉及账号密码，安全和合规风险大。
- 不封装成完整的桌面 App（安装包、Electron 等），也不做手机 App 和云端部署。软件就是「本地文件夹 + 启动脚本 + 浏览器界面」。
- 不做出勤自动检测（定位、摄像头等）—— 隐私敏感，用户手动标记即可。

## 3. 核心概念与计费模型（最关键的一节）

### 3.1 名词
| 名词 | 定义 |
|---|---|
| **学期 Semester** | 一段有起止日期、有一笔学费的时间段。一个学位可以有多个学期（如 Sem 1 / Sem 2 / Summer）。 |
| **课程 Course** | 一门课，例如 `MFIN7001 Corporate Finance`。可设学分、颜色、别名。 |
| **课节 Session** | 一次具体的上课，有开始时间、结束时间，属于某门课程。由日历事件（含重复规则）展开得到。 |
| **日历源 Calendar Source** | 导入的 `.ics` 文件，或一个 iCal 订阅链接。 |
| **单价 Rate** | 每秒钟上课对应的学费（HK$/秒）。 |

### 3.2 学费怎么分摊到每一秒？
用户只需要输入：**某学期的学费总额 T**（手动输入，可选币种）。
软件从日历里拿到该学期所有课节，算出总计划上课秒数 D。

**模式 A：按时长均摊（默认）**
```
每秒成本 r = T / D
某节课成本 = r × 该节课时长
```
> 验证：原版截图里每秒 HK$0.3685，一节 3 小时课 ≈ HK$3,980；历史 118,107 + 剩余 279,893 = 398,000，约等于 100 节 3 小时课。模式 A 可以复现这个结果。

**模式 B：按课程学分加权（进阶）**
不同课的学分 / 课时比不一样时更准确：
```
课程 k 的学费 T_k = T × 学分_k / Σ学分
课程 k 的每秒成本 r_k = T_k / 课程 k 的总课时秒数
```
学分默认相等（等价于每门课分到同样多的钱）。

> 上面的 T 指一个「学费池」的金额。学费池是按学期还是按学年，由首次启动时的选择决定，见 §3.5。

### 3.3 各项数字怎么算
设当前时间为 `now`（系统时钟，见 §5.4 时钟校准）：

| 显示项 | 计算方式 |
|---|---|
| 本节课已消耗 | `r × (now − 本节开始时间)`，截断在 [0, 本节成本] |
| 本节课剩余 | `本节成本 − 本节已消耗` |
| 已上课时长 / 剩余时长 | `now − start` / `end − now` |
| 本节进度 % | `已上课时长 / 本节总时长` |
| **历史总消耗** | `Σ 所有已结束课节成本 + 当前课节已消耗` |
| **剩余总学费** | `T − 历史总消耗` |
| 学期进度 % | `历史总消耗 / T` |
| 第几节 | 本课程第 i / N 节；本学期第 j / M 节 |

**关键设计：所有数字都由「课表 + 当前时间」推导，不依赖软件一直开着。** 哪怕你一周没打开，再打开时历史消耗也是对的。只有「摸鱼记录」「翘课标记」这类用户行为需要存储。

### 3.4 停课、翘课、迟到怎么算？
原则：**学费已经交了，「消耗」只跟时间走；有没有真正上课是另一个维度。** 这样「已消耗 + 剩余 = 学费总额」永远成立，数字不会回溯跳变。

| 情况 | 处理 | 额外统计 |
|---|---|---|
| 正常上课 | 计入消耗 | — |
| **停课**（老师取消） | 仍计入消耗 | 计入「被学校吞掉的学费」 |
| **翘课**（用户标记「我没去」） | 仍计入消耗 | 计入「翘课损失」，出勤率下降 |
| **迟到 / 早退** | 仍计入消耗 | 迟到的分钟数计入「迟到损失」 |
| **补课 / 加课**（日历外） | 用户手动添加课节 → 会改变 D 和 r | 弹窗提示「单价将从 X 变为 Y，是否重算」 |

> 待确认（见 §11）：停课是否应该从分母里剔除（即剩下的课变贵）。当前方案选择「不剔除」，因为更直观、数字更稳定、而且更有梗。

### 3.5 计费周期：按学期 or 按学年（首次启动必选）

| 选项 | 学费怎么填 | 怎么算 |
|---|---|---|
| **按学期** | 填「每学期学费」（默认每个学期相同，之后可在设置里单独改某个学期） | 每个学期是一个独立的学费池：该学期学费 ÷ 该学期总课时 = 该学期每秒成本。上下学期课时不同，单价也会不同。 |
| **按学年** | 填「一学年学费」 | 整个学年是一个学费池：学年学费 ÷ 全年总课时。学期划分只用于统计展示（如「上学期花了多少」）。 |

**学年与学期的边界**
- **学年起始日**：默认 9 月 1 日（北半球）。
- **学期分割日**：默认 **12 月 31 日**。学年起始日到分割日前一天的课属于上学期，分割日及以后的课属于下学期。
- **地区预设**（首次启动可选）：
  - 北半球（默认，港、英、美、加、新、欧）：学年起始 9/1，分割日 12/31。
  - 南半球（澳、新西兰）：学年就是自然年，上学期约 2–6 月、下学期约 7–10/11 月 → 学年起始 1/1，分割日 7/1。
- **手动调整**：学年起始日、分割日在首次启动和设置里都能改，用于学期安排比较特殊的学校。
- **智能检查**：导入日历后，软件找出学年内最长的「无课空档」（通常就是寒假）。如果分割日不在这个空档里（比如某学校 12 月底还在上课），就提示「检测到你的寒假是 12/20–1/12，建议把分割日改为 1/1」，可一键采纳。
- 分割日只要落在寒假里，具体选哪天都不影响任何金额（因为寒假没课）。
- 暑期学期（Summer Term）：P2，支持在学年里加第三个学期。

**默认值依据（2026–27 学年调研）**

| 学校 | 上学期结课 | 下学期开课 | 来源 |
|---|---|---|---|
| HKUST | 2026-12-19（暂定） | 1 月 | [HKUST Registry](https://registry.hkust.edu.hk/calendar_dates/dates26-27prov.pdf) |
| HKU SPACE CC | 12-14 | 1-22 | [HKU SPACE CC](https://www2.hkuspace.hku.hk/cc/f/page/40665/412435/CC%20Academic%20Calendar%202026-27%20(15%20May).pdf) |
| UCL | 12-18 | 约 1-11 | [UCL](https://www.ucl.ac.uk/students/life-ucl/term-dates-and-closures) |
| Imperial | 12-11 | 约 1 月初 | [Imperial](https://www.imperial.ac.uk/admin-services/registry/term-dates/) |
| U of Toronto | 12-07 | 1-11 | [UofT](https://artsci.calendar.utoronto.ca/) |
| Melbourne / Sydney | 上学期 2–6 月 | 下学期 7 月底开课 | [UniMelb](https://unimelb.edu.au/dates/semester-dates)、[USyd](https://sydney.edu.au/students/study-dates.html) |

结论：北半球学校上学期多在 12 月 7–19 日结课，下学期 1 月上中旬开课，圣诞节在所有调研学校的寒假内，所以默认 12/25 是安全的；南半球需要单独的预设。（部分日期来自暂定日历或第三方汇总，仅用于定默认值。）

### 3.6 货币

- 支持 7 种：**港币 HKD、人民币 CNY、美元 USD、英镑 GBP、欧元 EUR、加币 CAD、澳元 AUD**。
- 输入学费时可以切换币种；所有金额默认用学费的币种显示。
- 可选「换算显示币种」：主数字下方小字显示，如「≈ ¥2,450」。
- **汇率内置固定**：软件自带一张汇率表（标注更新日期，发新版时更新），设置里可以手动改。不联网获取。
- 等价物价格按各自的币种保存（如三餸饭 HK$45），显示时按汇率换算成当前币种。

## 4. 日历导入与课程识别

### 4.1 支持的导入方式
| 方式 | 优先级 | 说明 |
|---|---|---|
| **上传 `.ics` 文件** | P0 | Google Calendar「设置 → 导入与导出 → 导出」会得到一个 zip，里面每个日历一个 `.ics`。支持直接拖入 `.ics` 或整个 `.zip`。 |
| 粘贴 iCal 订阅链接 | P1 | Google Calendar 每个日历都有「iCal 格式的私密地址」。由本地服务（不是浏览器）去下载，所以不受浏览器跨域限制。启动时自动同步一次，之后每 6 小时同步一次，也可以手动点「立即同步」。链接属于隐私，只保存在本机 `data/` 里。 |
| 手动建课 | P1 | 没有日历的学校：手动填「课程名 + 每周几 + 几点到几点 + 起止日期 + 跳过日期」。 |

### 4.2 解析要求
- 支持 `VEVENT` 的 `DTSTART/DTEND`、`RRULE`（每周重复）、`EXDATE`（例外日期，如公众假期）、`RECURRENCE-ID`（某一次被单独改时间）、`TZID` / `VTIMEZONE` 时区。
- 按学期起止日期展开重复事件，得到具体课节列表。
- 默认忽略全天事件。
- 重新导入同一日历时，按 `UID + RECURRENCE-ID` 合并，**保留用户已经做过的标记**（翘课、改名、学分等）。

### 4.3 课程识别（导入后的确认步骤）
学校导出的日历里可能混着非上课事件（考试、Reading Week、讲座、个人事项）。导入后进入「识别课程」页面：
1. 按事件标题自动分组，并用正则提取课程代码（如 `[A-Z]{4}\d{4}`），同一代码的 Lecture / Tutorial 自动归为一门课。
2. 每组显示：标题、出现次数、总时长、示例时间。
3. 用户勾选「这是课」，可以合并分组、改课程显示名、设学分、选颜色。
4. 底部实时预览：本学期共 M 节课、总计 X 小时、每秒成本 HK$r、每节平均 HK$y。

### 4.4 开源扩展点
- 「学校预设」：社区可以提交某学校的识别规则（课程代码正则、Lecture/Tutorial 关键词、常见非课程事件关键词）。首发内置一个通用规则 + 示例数据。

## 5. 自动上课检测（状态机）

### 5.1 状态
| 状态 | 判定 | 主界面显示 |
|---|---|---|
| **学期未开始** | now < 第一节课 | 「距开学还有 X 天」+ 学费总额 |
| **上课中** | 存在课节使 start ≤ now < end | 实时计价主界面 |
| **课间** | 今天还有下一节课 | 下一节课倒计时、这节课的结算小卡片 |
| **今日已下课 / 今天没课** | 今天没有后续课节 | 今日小结 + 下一次上课时间 |
| **学期已结束** | now ≥ 最后一节课结束 | 学期总结 + 生成分享卡 |

### 5.2 检测方式
- 前端每帧（或每 100ms）根据当前时间计算状态，**不需要用户点「开始上课」**。
- 两节课时间重叠时：优先显示用户标记过「会去」的那节；否则显示先开始的那节，并给出切换按钮。
- 电脑睡眠 / 合盖再打开后，直接按当前时间重算，不会出现计时偏差。

### 5.3 提醒（P1）
- 上课前 N 分钟浏览器通知：「5 分钟后 MFIN7001 开始，这节课值 HK$3,980」。
- 下课时通知：「这节课结束，你摸鱼 12 分钟，浪费 HK$265」。

### 5.4 时间来源
- 以电脑系统时间为准。Windows / macOS 默认会自动联网对时，误差通常不到 1 秒，软件本身不联网校时。
- 课程时间按日历里的时区换算成绝对时间，所以电脑时区设置不影响「是否在上课」的判断。
- 关于页提示：如果发现计时对不上，请检查系统的「自动设置时间」是否开启。

## 6. 功能清单与优先级

> P0 = MVP 必须有；P1 = 第一个公开版本应该有；P2 = 以后再说 / 社区来做

### 6.1 设置与数据
| 功能 | 优先级 |
|---|---|
| 首次启动引导：**选择语言（默认英文）** → 学校名 + 地区预设 → **选择按学期 / 按学年计费、币种并输入学费（按学期最多两个学期）** → 确认学年起始日与学期分割日 → 导入日历 → 识别课程 → 预览确认（见 §3.5、§3.6） | P0 |
| 7 种货币切换（HKD / CNY / USD / GBP / EUR / CAD / AUD） | P0 |
| 学期分割日智能检查（导入后检测寒假空档并给出建议） | P1 |
| 多学年管理（新学年导入新课表、历史学年归档） | P1 |
| 计费模式切换（时长均摊 / 学分加权） | P1 |
| 课节手动编辑：标记停课、翘课、迟到、补课 | P0（翘课）/ P1（其他） |
| 数据导出 / 导入 JSON（备份、换电脑） | P1 |
| 示例数据 / 演示模式（不导入也能看效果，方便开源项目展示） | P0 |
| 多语言：简体中文 / 繁體中文 / English | P1 |
| 换算显示第二币种（如同时显示「≈ ¥2,450」，内置固定汇率，可手动改） | P1 |

### 6.2 上课主界面（Dashboard）
| 功能 | 优先级 |
|---|---|
| 本节课：课程名、第 i/N 节、已消耗（实时跳动）、剩余、每秒成本、已上 / 剩余时长、进度 | P0 |
| 学期：历史总消耗、剩余学费、学期进度 | P0 |
| 今日时间线：今天所有课节在一条时间轴上，当前位置高亮 | P1 |
| 轮播文案条：根据当前数据生成的毒舌 / 鼓励文案 | P0 |
| 白天主题（已取消夜间主题） | P1 |
| 防偷看模式：一键模糊所有金额（快捷键） | P1 |
| 迷你悬浮窗：只显示一个跳动的数字，置顶（用 Chrome / Edge 的「画中画小窗」实现） | P2 |
| 浏览器标签页标题实时显示金额（如「HK$2,687 · 上课中」），切到别的标签也能看到 | P1 |

### 6.3 摸鱼模式
| 功能 | 优先级 |
|---|---|
| 「我要摸鱼」按钮 → 全屏摸鱼页：「你已浪费 HK$x」实时跳动 | P0 |
| 等价物实时提示：金额越过阈值时切换文案（「已经浪费一瓶水」→「一杯奶茶」→「一盒三餸饭」） | P0 |
| 「继续听课」结束 → 结算卡：时长、金额、等价物、本节累计摸鱼 | P0 |
| 下课时自动结束摸鱼 | P0 |
| 摸鱼记录持久化（按课程、按日期） | P0 |
| 摸鱼统计页：总浪费、摸鱼率、最爱摸鱼的课、最长一次摸鱼 | P1 |
| 文案强度三档：温和鼓励 / 正常 / 焦虑拉满 | P1 |

### 6.4 等价物库
- 内置「香港物价包」：一瓶水、一杯奶茶、一次港铁、一盒三餸饭、一份麦当劳套餐、一张戏票、一个月 Netflix、一部 iPhone……（价格为大致参考，可改）。
- 用户可以自定义物品和价格（如「我家猫一个月的猫粮」）。
- 社区可提交其他城市物价包（深圳、新加坡、伦敦、悉尼……），P2。

### 6.5 统计与回顾

## 7. 界面与交互

### 7.1 视觉风格
- **设计流程**：界面设计阶段用 Claude Design（Claude 里的 Design 类型 Artifact）出设计稿；风格可以选一个现有的 Design System，也可以直接用本节写的风格。设计稿确认后再写前端。
- **基调**：不枯燥，也不复杂。一屏只突出一个大数字，其余信息退到次要层级；动效只用在「数字跳动」「摸鱼光斑」「结算卡弹出」这几处。
- **字体**：参照原版的气质 —— 数字用几何感强、粗重的无衬线体，配等宽数字（tabular-nums）防止跳动时抖动；中文用思源黑体 / 系统黑体；小标题用大写 + 加宽字距的英文。具体字体在设计阶段定（候选：Inter / DM Sans / Manrope + Noto Sans SC）。
- **配色**：
  - 浅灰白底 + 深海军蓝主数字 + 金棕色货币符号和强调色。
  - 摸鱼页：暖色渐变背景 + 漂浮的半透明光斑，营造「钱在慢慢溜走」的氛围。
- **布局不照抄原版**：原版是「一个大卡片 + 网格小卡片 + 进度条」，我们换一套结构（见 7.2）。

## 8. 数据模型（概念层）

```
Settings      { 语言, 主题, 币种, 显示换算币种, 汇率表, 文案强度, 地区预设 }
AcademicYear  { id, 名称, 起始日, 学期分割日, 计费周期(semester|year), 计费模式(时长均摊|学分加权) }
TuitionPool   { 学年id, 学期序号(按学年计费时为空), 学费, 币种 }
CalendarSource{ id, 类型(file|url), 原始ics文件, 订阅链接, 最后同步时间 }
Course        { id, 学年id, 代码, 显示名, 学分, 颜色, 匹配规则(标题/正则) }
Session       { id(=UID+RECURRENCE-ID), 课程id, 开始, 结束, 来源(日历|手动) }
SessionMark   { sessionId, 状态(正常|停课|翘课), 迟到分钟, 早退分钟, 备注 }
SlackRecord   { id, sessionId, 开始, 结束, 金额(按当时单价) }
EquivalentItem{ id, 名称, emoji, 价格, 币种, 来源包 }
```
存储：本地服务把数据写成 JSON 文件，放在软件文件夹的 `data/` 目录里（导入的日历原文件也存在这里）。每次写入前自动备份，保留最近若干份。拷走整个文件夹就是完整迁移。不上传任何服务器。

## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| **启动** | 双击 `start.cmd`（Windows）/ `start.command`（macOS）即可：检查 Node.js → 启动本地服务 → 自动打开浏览器。没装 Node 时给出中文提示和下载地址。已经在运行时再双击，只打开浏览器、不重复启动。关闭命令行窗口即停止服务。 |
| **隐私** | 课表、学费、摸鱼记录全部只存在本机 `data/`；服务只监听 127.0.0.1，外部设备访问不到；不接入统计 / 广告 SDK；README 里写清楚。 |
| **离线** | 除订阅链接同步外完全不联网；字体等资源全部随软件打包，不依赖 CDN。 |
| **运行环境** | Node.js 22 LTS 及以上；用户只需安装 Node，不需要执行任何 npm 命令（发布包里已包含构建好的前端）。 |
| **准确性** | 金额计算用整数分（或高精度小数）避免浮点累积误差；显示保留 2 位小数；计价与时钟严格同步。 |
| **性能** | 实时跳动动画流畅（60fps），常驻标签页 CPU 占用低；后台标签页降频。 |
| **兼容** | 最新版 Chrome / Edge / Safari / Firefox；Windows（主）+ macOS。 |
| **可访问性** | 金额支持屏幕阅读器播报（低频）；颜色对比度达标；不只靠颜色表达状态。 |
| **开源** | MIT 许可证；README 中英双语；提供示例 `.ics`；贡献指南说明如何添加学校预设 / 物价包 / 翻译。 |

## 10. 边界情况

| 情况 | 处理 |
|---|---|
| 日历里有跨午夜的课 | 正常处理，按绝对时间计算 |
| 夏令时切换（英美学校） | 依赖 `TZID` 正确换算 |
| 人在外地 / 换时区 | 计算用绝对时间，显示用本地时间，并标注课程所在时区 |
| 同一时间两门课重叠 | 见 §5.2 |
| 学校更新了日历 | 重新导入后合并，保留标记；单价变化时提示 |
| 某学期日历里一节课都没识别出来 | 引导用户回到识别页或手动建课 |
| 学费为 0 或未填 | 不允许完成引导 |
| 摸鱼中关掉网页 | 重新打开时恢复摸鱼状态（开始时间已存储），或在下课时间点自动截断 |
| 本机时间被改错 | 以系统时间为准，见 §5.4 |
| 某节课正好跨过学期分割日 | 按课节开始时间归属学期 |
| 按学期计费但某学期没填学费 | 该学期显示「未设置学费」并引导填写，不影响其他学期 |
| 端口被其他程序占用 | 自动换下一个可用端口 |

## 11. 决策记录与待确认问题

**已确认（v0.2）**
- 形态：本地文件夹 + `start.cmd` 启动本机 Node 服务 + 浏览器显示；需要安装 Node.js；数据存在 `data/` 目录。
- 计费周期：首次启动由用户选择「按学期」或「按学年」；学期分割日默认 12/25，可调（§3.5）。
- 货币：7 种；汇率内置固定，可手动改（§3.6）。
- 时间：以电脑系统时间为准（§5.4）。
- 订阅链接同步：由本地服务实现（§4.1）。
- 测试数据：你的 Google Calendar 导出已放在 `test-data/private/`（不会提交到 git）。

**仍待确认（不阻塞开发，先按默认做）**
1. **停课计费**：默认「停课也算消耗，单独统计为被学校吞掉的钱」。另一种是「停课不算、剩下的课变贵」。
2. **默认分摊方式**：默认「按时长均摊」（和原版一致）。
3. **产品名**：暂定「学费计价器 / Tuition Ticker」。
4. **MVP 范围**：§6 里标 P0 的是第一版必做，有需要提前或推后的可以提。
